## 使用するソフトウェアのインストール

※ bash または zsh での操作を想定してます。

まずは、Node.js と SQLite をインストールしましょう。ここはググってください。

次に、プロジェクトを作成するディレクトリに移動してください。

その後、以下のコマンドを実行してください。

```bash
$ mkdir backend && cd backend/ # backend というフォルダを作成＆移動
$ npm i body-parser dot-env express method-override sequelize sqlite3 # アプリケーションで使う FW と ライブラリのインストール
$ npm i -D @eslint/js esbuild eslint globals prettier # 開発を楽にする FW と ライブラリのインストール
```

以下にインストールしたソフトウェアとその用途について解説しておきます。

### アプリケーションで使うもの

`npm i` でインストールしたものです。

|名称|用途|
|:--:|:--|
|body-parser|リクエストボディの解釈をするツール|
|dotenv|`.env` (環境設定を分離するファイル) の読み込みをするツール|
|express|サーバーサイドフレームワーク|
|method-override|HTTPメソッドを書き換えるツール(ex: POST -> DELETE)|
|sequelize|プログラム言語とデータベースを操作する言語(SQL)の仲介をするツール(ORM: *Object-Relational Mapping*)|
|sqlite3|SQLite を操作するための言語|

### 開発で使うもの

`npm i -D` でインストールしたものです。

|名称|用途|
|:--:|:--|
|@eslint/js|eslint の設定に使う|
|esbuild|複数あるソースコードを1つにできるツール(ビルドツール)|
|eslint|JS(TS)用のリンター|
|globals|eslint の設定に使う|
|prettier|フォーマッター|

## ディレクトリの設定

が存在しません。

また、以後ファイル名を指す際には、`backend/` を除外して指示します。

## サーバーでのハローワールド

まずは、`src/` ディレクトリを作成しましょう。以後、ソースコードはここに格納します。

今回はサーバーサイドフレームワークに express.js を用います。

公式サイトの以下のコードを `server.js` に目コピしてみましょう。

```js
const express = require('express');
const app = express();
const port = 3000;

app.get('/', (req, res) => {
  res.send('Hello World!');
});

app.listen(port, () => {
  console.log(`Example app listening on port ${port}`);
});
```

この後、対応する npm スクリプト (fix -> lint -> build -> start) を実行してみてください。
`npm run start` に関しては、ファイル名が関係しているので、`src/app.js` などにした場合は、適宜修正してください。

この `npm run start` では、サーバーの起動を行います。これを実行後 [localhost:3000](http://localhost:3000) にアクセスしてみてください。
ブラウザの画面に "Hello World!" と表示されていれば、一連の流れは成功です。

ここで、エンドポイントを `/`  以外に増やしてみてもいいかもしれません。

## フレームワークの設定

今回はディレクトリ構成を堅牢にしたいので、フレームワークを設定するファイルは独立させましょう。

`configs/` というディレクトリ内に `express.js` というファイルを作成し、以下の内容を記載してください。

```js
"use strict";
const express = require("express");
const bodyParser = require("body-parser");
const methodOverride = require("method-override");

// アプリの実体を定義する
function setupExpress()  {
  const app = express();
  // POST 経由でメソッドを上書きできるように
  app.use(methodOverride("_method"));
  // リクエストボディの取得
  app.use(bodyParser.urlencoded({ extended: true }));
  app.use(bodyParser.json());
  // ルーター定義(後で出てきます)
  return app;
};

module.exports = { setupExpress };
```

これを先ほどの `server.js` と紐づけましょう。

```js
"use strict";
// セットアップ用関数
const { setupExpress } = require("./config/express.js");

// ポート番号
const PORT = 3000;

// 起動用関数
async function main() {
  const app = setupExpress();
  app.listen(PORT, () => {
    console.log(`Example app listening on port ${PORT}`);
  });
};
// サーバーの起動
main().catch(console.error);
```

この時点でサーバーを一度起動してみましょう。
お気づきかもしれませんが、この時点での `/` に対するリクエストを処理するロジックがありません。
練習として、これを追加してみましょう。
