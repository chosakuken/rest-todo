# 第 2 回： データベースの環境構築

## ORM のセットアップ

今回は、ORM (*Object-Relational Mapping*) として、sequelize を用います。
ORM とは、プログラミング言語とデータベースを操作する言語 (SQL) を仲介するソフトウェアです。

また、データベースには SQLite を用います。
これらの理由は、使いやすいからです。
現代であれば、PostgreSQL が主流なはずです。

これらの設定として、`configs/sequelize.js` を用います。以下のソースコードを写経してみてください。

```js
"use strict";
const { Sequelize } = require("sequelize");

// データベースの実体を定義する
const sequelize = new Sequelize({
  dialect: "sqlite", // 使うデータベース
  storage: "./db/database.db", // データベースの実体の部分
});

// データベースをセッティングする関数
async function setupDatabase() {
  try {
    // 接続を確認する
    await sequelize.authenticate();
  } catch (e) {
    console.error(e);
  }
  // スキーマ設定等を同期する
  await sequelize.sync();
}

module.exports = { sequelize, setupDatabase };
```

これを `server.js` に反映させてみましょう。

```diff
"use strict";
// セットアップ用関数
const { setupExpress } = require("./config/express.js");

// ポート番号
const PORT = 3000;

// 起動用関数
async function main() {
  const app = setupExpress();
+ await setupDatabase();
  app.listen(PORT, () => {
    console.log(`Example app listening on port ${PORT}`);
  });
};
// サーバーの起動
main().catch(console.error);
```
