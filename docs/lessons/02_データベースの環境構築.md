# 第 2 回： データベースの環境構築

## ORM のセットアップ

今回は、ORM (*Object-Relational Mapping*) として、sequelize を用います。
ORM とは、プログラミング言語とデータベースを操作する言語 (SQL) を仲介するソフトウェアです。

また、データベースには SQLite を用います。
これらの理由は、使いやすいからです。
現代であれば、PostgreSQL が主流なはずです。

これらの設定として、`configs/sequelize.js` を用います。以下のソースコードを写経してみてください。

```js
"use strict";
const { Sequelize } = require("sequelize");

// データベースの実体を定義する
const sequelize = new Sequelize({
  dialect: "sqlite", // 使うデータベース
  storage: "./db/database.db", // データベースの実体の部分
});

// データベースをセッティングする関数
async function setupDatabase() {
  try {
    // 接続を確認する
    await sequelize.authenticate();
  } catch (e) {
    console.error(e);
  }
  // スキーマ設定等を同期する
  await sequelize.sync();
}

module.exports = { sequelize, setupDatabase };
```

これを `server.js` に反映させてみましょう。

```diff
// 起動用関数
async function main() {
  const app = setupExpress();
+ await setupDatabase();
  app.listen(PORT, () => {
    console.log(`Example app listening on port ${PORT}`);
  });
};
```

これを作成した後、実行 (`npm run start`) してみてください。
一連の流れが成功していれば、`db/database.db` が生成されるはずです。
SQLite は単純で、この `database.db` に直接データが書き込まれる形になります(ただし、`cat` などで見れる訳ではない)。

## データのスキーマ定義

次に、どんなデータを作るかのスキーマ定義に入ります。
[公式サイト](https://sequelize.org/docs/v6/core-concepts/model-basics/) を参考に `src/models` 直下に新規ファイルを作ってみましょう。また、この際の拡張子は、分かりやすく `.model.js` としましょう。

以下に ToDo リストのタスクを一例に示したいと思います。

```js
"use strict";
const { sequelize } = require("../config/sequelize.js");
const { DataTypes } = require("sequelize");

// 第1引数 がテーブル名となる
const Task = sequelize.define("Task", {
  id: {
    type: DataTypes.INTEGER, // 整数型
    allowNull: false, // 空を不許容
    autoIncrement: true, // 自動増分
    primaryKey: true, // 主キー
  },
  name: {
    type: DataTypes.STRING, // 文字列型
    allowNull: false,
  },
  detail: {
    type: DataTypes.STRING,
    allowNull: true, // 空を許容
  },
  deadline: {
    type: DataTypes.DATE, // 日付型
    allowNull: false,
  },
  done: {
    type: DataTypes.BOOLEAN, // 真偽値型
    allowNull: false,
  },
});

module.exports = { Task };
```

この後適宜 Task を呼び出すと、自動的に Task テーブルが生成されているはずです。
